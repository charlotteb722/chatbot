# AI for customer enquiries: content set

Drafts for review, written in Charlotte's practical AI teaching style.

| File | What it is | Length |
|---|---|---|
| `article.md` | Website or blog explainer | ~850 words |
| `linkedin-post.md` | Short post pointing to the same idea | ~170 words |
| `prompt-card.md` | Reusable prompt and checklist readers can copy | 1 page |

## Assumptions to check

- No statistics or client results are included. Add real examples only if you have them.
- Tools are named generically (ChatGPT, Claude, Copilot). No product is recommended.
- No service offer, price or availability is mentioned. Add a call to action if you want one.
- Data protection is flagged as something to check, not given as legal advice.
